Easiest: open an issue (no code)

  1. Tap Request a name below. You'll need a free GitHub account.
  2. Fill the form: name, category, gender (m or f, only used to pick the emoji).
  3. Submit. A maintainer adds it.
Request a name

Pro move: send a pull request

  1. Fork the repo (button at the top right on GitHub).
  2. Open people.json and tap the pencil icon to edit.
  3. Add your entry at the end of the list, copying this shape: 
    {
  "id": "firstname-lastname",
  "name": "Firstname Lastname",
  "cat": "YouTuber",
  "gender": "f"
}
  4. id: lowercase letters, numbers and hyphens, unique. cat: TV Anchor, Journalist, YouTuber or Influencer. gender: m or f.
  5. Commit, then tap Contribute → Open pull request. A bot checks your JSON automatically.
  6. Once merged, the site and the voting API pick the name up on their own.
Edit people.json
House rules: public figures only (people with a public media presence in India), no private individuals, no personal details, no insults in the name field. Want a name removed or corrected? Open an issue and say why. Every request is reviewed.

Your feed shouldn't gaslight you.

Anchors, YouTubers and influencers shape what millions believe. JhoothMeter gives the audience a scoreboard. Tap the 🤥 on the names you feel mislead the public and watch the ranking move.

  • Anonymous: no login, no email, no tracking. Your device holds a random code, and the server only stores a scrambled version of it.
  • Like-style voting: tap to vote, tap again to undo. One vote per person per name.
  • Shared and persistent: everyone sees the same live scores, saved on the server.
  • Free forever: it runs on free tiers. If a daily limit is hit, your vote waits on your device and syncs later.
  • Spread it: every card has a share button. Send your pick to the group chat.
Important: this is an opinion poll. A vote is one viewer's opinion, not a finding of fact, and the ranking says nothing about any person's intent or honesty. Names are listed because they are widely followed public figures, not because we claim anything about them. Scores can be skewed by campaigns, so read them as a mood, not a verdict.

The code, the name list and the rules are open on GitHub, so anyone can check how it works.
